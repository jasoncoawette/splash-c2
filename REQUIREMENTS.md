## Rules

- A requirement without a named source or observed operator problem is deleted or deferred.
- Demo assumptions must be labeled as assumptions.
- Core functions do not read clocks, browser APIs, React state, Redux state, or sockets.
- Core functions return new values rather than mutating their inputs.
- Automation is added only after the manual behavior is understood and stable.
